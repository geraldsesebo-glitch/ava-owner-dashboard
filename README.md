# Ava owner dashboard (static page)

The sign-in page and dashboard for a company owner. Plain HTML, CSS and JavaScript; no build step, no outside libraries.

The page contains only the public project address and the public (anon) key. It holds no secret. Nothing can be seen or changed without signing in: every read and action is checked by the database against the signed-in person's own company membership.

Source of record: the owner's private repository (`apps/owner-dashboard-v2`).
